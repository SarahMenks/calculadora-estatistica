# calculadora-estatistica

### Calculadora de operações estatísticas simples em C++.

_Usado como um exemplo para disciplina Engenharia de Software II._

## Como Executar

### Pré-requisitos
- Compilador C++ (`g++` ou `clang++`)
- `make`
- `docktest.h` ou `curl` (para download automático do arquivo)

### Executando os Testes
Basta rodar o comando abaixo no terminal para baixar as dependências, compilar e rodar os testes:

```bash
make
```
